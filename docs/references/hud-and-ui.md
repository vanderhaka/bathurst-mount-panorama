# HUD and UI

Broadcast-style and sim-racing HUD references: Supercars TV graphics (leaderboard totem, lower thirds, grids), native sim HUDs (F1, Gran Turismo, Forza, ACC, iRacing, AMS2, rFactor 2), community overlay and dash ecosystems (SimHub, RaceLab, iOverlay), MoTeC displays, shift-light designs, minimap and track-map overlays, timing data models, and typography, colour and layout resources. Coverage is thinner for delta-bar and damage-indicator designs; the F1 on-screen-display catalogue, ACC patch notes and overlay videos are the closest references found.

Descriptions of photos and videos are written from page titles, captions and metadata; the media itself was not downloaded, so check the framing before relying on a specific angle. Every URL was fetched or came from a search result when this library was compiled (2026-10-07); a few sites (for example artstation.com, bathurst.nsw.gov.au, cgtrader.com, fandom.com) refuse automated requests with 403 or 202 responses but did appear in search results.

**Reference count: 73**

## Typography, colour and layout for a broadcast-style HUD (17)

- [Google Fonts: Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed) — Condensed grotesque suited to timing towers and narrow data rows.
- [Google Fonts: Saira Condensed](https://fonts.google.com/specimen/Saira+Condensed) — Sporty condensed face with a motorsport feel for headings and driver names.
- [Google Fonts: Rajdhani](https://fonts.google.com/specimen/Rajdhani) — Squared geometric face used in digital dashboards.
- [Google Fonts: Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch) — Technical-looking face for HUD labels and corner names.
- [Google Fonts: Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono) — Monospaced digits so changing lap times do not jitter.
- [Google Fonts: B612 Mono](https://fonts.google.com/specimen/B612+Mono) — Monospace face designed for cockpit displays, strong legibility for numbers.
- [Google Fonts: Titillium Web](https://fonts.google.com/specimen/Titillium+Web) — Neutral techno-sans widely used for sports and racing UI.
- [Google Fonts: Teko](https://fonts.google.com/specimen/Teko) — Tall condensed display face for big gear and speed numerals.
- [MDN: font-variant-numeric](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-numeric) — How to switch on tabular figures so timing digits do not shift.
- [Colour Universal Design (CUD) / colour-blind barrier-free guide](https://jfly.uni-koeln.de/color/) — Colour-blind-safe palette guidance for purple/green/yellow sector colours and flags.
- [ColorBrewer](https://colorbrewer2.org/) — Tool to pick colour-blind-safe sequential and diverging scales for delta and tyre-wear bars.
- [MDN: colour contrast (WCAG)](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Perceivable/Color_contrast) — Contrast ratio guidance for HUD text on busy 3D backgrounds.
- [three.js: CSS2DRenderer](https://threejs.org/docs/pages/CSS2DRenderer.html) — Overlay HTML labels (corner names, driver tags) anchored to 3D points.
- [three.js example: css2d label](https://threejs.org/examples/css2d_label.html) — Working example of HTML labels tracking 3D objects, a pattern for driver tags and corner callouts.
- [three.js: OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html) — Camera used for a top-down minimap render or an in-scene HUD layer.
- [MDN: Canvas API](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) — Canvas basics for drawing the minimap, rev bar and delta bar at 60 fps.
- [MDN: SVG](https://developer.mozilla.org/en-US/docs/Web/SVG) — SVG basics for crisp gauges and track outlines in the HUD.
